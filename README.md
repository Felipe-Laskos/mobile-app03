# App03 – Grimório de Hogwarts

Trabalho da disciplina DS151 – Desenvolvimento para Dispositivos Móveis.

App Android (Kotlin, minSdk 29) que consulta a [Hogwarts API](https://hogwarts-api.com) para buscar personagens e criaturas do mundo bruxo.
